# odoo-module

Odoo backend modules by Aditya.

| Module | Description |
| --- | --- |
| [`my_backend_theme`](my_backend_theme/README.md) | Configurable backend theme for Odoo 20: colors, dark mode, sidebar, quick create, bookmarks, recently viewed, workspace tabs, split view, record search and command palette |
| `my_backend_theme_mail` | Chatter position for `my_backend_theme` (installs itself with `mail`) |
